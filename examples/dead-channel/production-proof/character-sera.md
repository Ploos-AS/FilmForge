# Sera Vale — Character Reference Bible

## Function
Sera is the audience's single stable human anchor through most of Film #1.

## Profile
Age range: early-to-mid 30s.
Role: communications technician on the remote Kestrel listening station.
Temperament: competent, dry, observant, emotionally guarded rather than cold.

## Visual continuity
Keep the design practical and reproducible:
- short-to-medium dark hair with a consistent silhouette;
- no elaborate hairstyle;
- workwear built from charcoal utility layers;
- one muted undershirt;
- station ID patch on left chest;
- compact wrist terminal;
- no jewelry except one small personal token kept under clothing.

Avoid visually trendy cyberpunk styling. Sera should look like someone doing an ordinary technical job in an extraordinary setting.

## Performance language
Sera rarely narrates feelings. Emotion appears through pauses, aborted actions, listening behavior and changes in how quickly she responds.

Early film: economical movement, routines, avoids unanswered personal messages.
Middle: increasingly still while listening to Cael.
Ending: deliberately reaches for transmit rather than receive controls.

## Continuity anchors
Every generated shot involving Sera should reference:
- canonical face reference set;
- canonical workwear turnaround;
- hair silhouette;
- ID patch placement;
- wrist-terminal placement;
- current scene emotional state.

## Generation risk
Low-to-medium. A single primary character is favorable, but closeups across an 18-minute film require a locked reference workflow.
