# FilmForge M0

## Objective

Demonstrate that FilmForge can represent and orchestrate an AI-assisted short-film production without coupling the project to a single generative provider.

## Reference production

Target:

- original science-fiction universe
- 15–20 minute first film
- small principal cast
- 2–4 major locations
- strong visual identity
- self-contained dramatic payoff
- unresolved larger-world questions suitable for later films

The first film is both a creative work and the system integration test.

## M0 deliverables

1. Project manifest.
2. Universe/world bible structure.
3. Character, location, prop and style identities.
4. Scene and shot data model.
5. Provider-neutral generation request format.
6. Continuity notes and review states.
7. Output lineage: source -> prompt -> generation -> selected take.
8. Reference-production outline.
9. CLI contract for the next milestone.

## Proposed CLI contract

```text
filmforge init <project>
filmforge validate <project>
filmforge plan <project>
filmforge shots <project>
filmforge prompts <project>
filmforge review <project>
filmforge assemble <project>
```

M0 defines these commands; M1 can implement the first executable subset.

## Non-goals

M0 does not attempt to:

- generate a complete film
- choose a permanent model/vendor stack
- implement a nonlinear editor
- replace professional finishing tools
- fully automate creative approval
